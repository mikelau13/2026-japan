## 2. えきねっと早割説明

えきねっと（JR東日本網上訂票系統）提供新幹線早鳥折扣，可大幅降低票價：

| 早割種類 | 購票期限 | 折扣幅度 | 備註 |
|---------|---------|---------|------|
| **お先にトクだ値（スペシャル）** | 35日前 | 最高35%折扣 | 名額少，最早開搶 |
| **お先にトクだ値** | 28日前 | 最高30%折扣 | 次優先 |
| **えきねっとトクだ値** | 14日前 | 最高15%折扣 | 臨近出發仍有折扣 |

**注意事項**：
- 早割票一旦購買，更改或退票手續費較高
- 建議行程確定後盡早（35日前）預訂指定席
- 需えきねっと帳號（免費申請）；海外信用卡一般可用

## 3. JR East Pass 不划算分析

| 項目 | 金額 |
|------|------|
| JR East Pass 5日券（新幹線可用） | 35,000円/人 |
| 本行程 JR 實際費用/人 | 約23,000円/人（含新幹線全段） |
| **使用 Pass 多花** | **約12,000円/人** |
| **4人合計多花** | **約48,000円** |

**結論**：JR East Pass 不划算。建議個別購票，配合 **えきねっと早割** 享新幹線早鳥折扣，最高可省35%。
