## 新潟市簡介

新潟市是新潟縣縣廳所在地，面向日本海，為日本海側最大城市之一。以越光米、日本酒、海鮮著名，夏季氣候溫熱多濕。6月底至7月初氣溫約25-30°C。

### 古町・本町 位置關係

古町和本町是**同一個街區**，南北平行，中間只隔一條東堀通，步行約2–3分鐘可互相往來，實際遊覽時當作同一個區域逛即可。

```
信濃川（北）
  ↓
本町通 ── 本町市場（ぷらっと本町）── 傳統生鮮市場，早上最熱鬧
  │  ← 東堀通（一條街之隔，步行2–3分）
古町通 ── 古町商店街 ── 餐廳、居酒屋、老舖，傍晚至夜間最有氣氛
  ↓
新潟駅方向（南）
```

| | 本町 | 古町 |
|--|------|------|
| 性質 | 傳統市場（生鮮、海產、蔬果） | 商店街＋飲食街（餐廳、居酒屋、老舖） |
| 最佳時段 | 早上至下午，買零食食材 | 傍晚至夜間，吃晚餐 |
| 代表 | ぷらっと本町（室內市場街） | へぎそば、タレかつ丼各名店 |

**實際建議**：Day 1 下午無需分先後，把兩條街當同一街區來回穿插逛，自然就都走到了。

## 順道打卡地標（免費）

> 以下地標均為**免費**，不需額外購票，路過即可拍照，不影響主要行程節奏。
> 部分有夜間燈光效果，白天夜晚各有不同風情。

| 項目 | 內容 |
|------|------|
| 位置 | JR新潟駅 **万代口（北口）**正前方，東大通中央分隔帶 |
| 費用 | **免費** |
| 所需時間 | **0分鐘**（出站即見，路過拍照） |
| 夜間 | 有燈光照明，夜拍效果佳 |
| 背景 | 新潟開港150週年紀念裝置，以英文字組成城市標誌 |

#### 拍攝時機
- **抵達當天（6/30）**：放完行李後第一步即可拍
- **每晚祭典歸來**：夜間燈光版本，順手拍
- **離開當天（7/2）**：往新幹線月台前最後留念

> 万代島（信濃川河口）有另一個**較大型版本**，拍攝效果更佳，但需步行約20–25分鐘特地前往，可視 Day 1 散步路線決定是否順路。

### 萬代橋（万代橋）

| 項目 | 內容 |
|------|------|
| 位置 | 信濃川上，万代口方向步行約20分鐘 |
| 費用 | **免費**（公共道路，可步行過橋） |
| 所需時間 | 步行過橋來回約10–15分鐘（含拍照） |
| 文化地位 | **國家重要文化財**（2004年指定，全日本國道橋梁中第二座獲此殊榮，僅次於東京日本橋） |
| 規格 | 全長306.9m、寬22m、6個緩弧拱 |
| 建造 | 1929年（昭和4年）竣工，為第三代橋樑，歷經新潟地震依然屹立 |
| 夜間 | 橋身常設夜間燈光（暖色系），倒映信濃川水面，極具攝影價值 |

#### 看點
- 站在橋上望向上下游，視野開闊，新潟市容一覽無遺
- 夜間從河岸遊步道拍橋倒影，是新潟最具代表性的夜景之一
- 御影石飾面，細看橋欄雕工精緻

#### 建議時機
- **Day 1 傍晚散步**：万代口方向出站，步行至橋，夕陽時分拍照，再折返蒲原神社方向晚餐
- **祭典夜間歸途**：若步行返回酒店，可繞經橋邊賞夜景（稍繞路，約多10分鐘）

### 蒲原神社 参道・鳥居（夜間燈籠）

| 項目 | 內容 |
|------|------|
| 位置 | 蒲原神社境內，從参道入口鳥居至神楽殿一線 |
| 費用 | **免費** |
| 所需時間 | **0分鐘額外**（進入祭典必經之路） |
| 夜間演出 | 蒲原まつり三夜（6/30、7/1、7/2）期間，参道兩側掛滿紙燈籠，夜間全部點亮 |

#### 夜間燈籠特色
- 数百個紙燈籠懸掛於参道兩旁，由鳥居一直延伸至神楽殿
- 橙黃燈光映照古木神社，氣氛莊嚴而溫暖
- 與露店的霓虹燈形成強烈對比：神社內側靜謐古典，外側熱鬧喧嘩
- **這是免費而且必看的畫面**，每晚進場時不要急著找露店，先慢步欣賞参道燈籠

#### 拍攝建議
- 進入神社後先不要急，在鳥居下回望参道全景
- 燈籠在天色完全暗後（約20:00後）效果最佳
- 人流較少的時段：御託宣結束後（19:30左右）人潮稍散，可再度拍攝

### 沼垂テラス商店街（Day 1 下午）

| 項目 | 內容 |
|------|------|
| 位置 | 新潟市中央区沼垂東3丁目、信濃川沿岸舊市場區 |
| 費用 | **逛街免費**（各店消費另計） |
| 所需時間 | 約1小時 |
| 新潟駅步行 | 約20分鐘（万代口方向出發） |
| 巴士 | 新潟交通バス→沼垂四ツ角站下車→步行2分 |

#### 什麼好看

昭和時代舊魚市場長屋完整改建為文青商店街，保留木造廊道原貌，共約30間獨立小店：

| 類型 | 推薦 |
|------|------|
| 玻璃工房 | taruhi glass works（可體驗玻璃珠製作） |
| 陶藝工房 | 青人窯（可入內參觀） |
| 自家烘焙咖啡 | VOST COFFEE、mountain△grocery |
| 復古雜貨 | 松本商店（昭和懷舊小物） |
| 海鮮料理 | 大佐渡たむら（午餐選項） |

#### ⚠️ 週一注意事項
- 週二・週三定休日的店最多，**週一相對較好**
- 部分週一也休的店會關門，但廊道建築本身全日開放
- 即使半數店家關門，復古木造長屋的氛圍和拍照效果不受影響
- 建議：入場先沿廊道走一圈拍照，再選開門的店進入消費
