## 新潟市歴史博物館みなとぴあ

### 基本資訊

| 項目 | 內容 |
|------|------|
| 地址 | 新潟市中央区柳島町2-10 |
| 官網 | https://www.nchm.jp/ |
| 電話 | 025-225-6111 |
| 營業時間 | 9:30–18:00（6月） |
| **休館日** | **每週一**・假日翌日・年末年始 |
| 入場費（常設展） | 大人390円／高中・大學生260円／小・中學生130円 |
| 週末特典 | **週六・日・假日小・中學生免費** |
| 建議停留 | 1.5–2小時 |

### 票價（咱家四口）— 7月1日（週三，平日）

| 家庭成員 | 年齡 | 對應分類 | 費用 |
|----------|------|----------|------|
| 爸媽 ×2 | 大人 | 一般 | 390円 ×2 = **780円** |
| 小孩 | 13歲 | 中學生相當 | **130円** |
| 小孩 | 15歲 | 高中生相當 | **260円** |
| **合計** | | | **1,170円** |

> **外國遊客實際操作**：告知工作人員小孩年齡即可，工作人員會自行對應分類。以年齡判斷為準，差額最多130円，工作人員通常不會計較。

### 交通

| 方式 | 詳情 |
|------|------|
| 巴士 | 新潟駅万代口巴士總站→約10分鐘 |
| 步行 | 從新潟駅約20-25分鐘 |

### 展示亮點

| 看點 | 說明 |
|------|------|
| **旧新潟税関庁舍** | 明治初期洋風建築，重要文化財 |
| **旧第四銀行住吉町支店** | 昭和初期古典主義建築，愛奧尼亞式列柱、大理石、馬賽克磁磚 |
| **復元早川堀・柳並木** | 明治至昭和港町景觀完整重現 |
| 常設展示 | 新潟港町歷史、蒲原平野農村文化、水與人的歷程 |
| 體驗廣場 | 互動式展示，邊玩邊學 |

> 7月1日（週三）開館，小・中學生票130円。

## 新潟せんべい王国

### 基本資訊

| 項目 | 內容 |
|------|------|
| 地址 | 新潟市北区新崎2661 |
| 運營 | 栗山米菓（「ばかうけ」製造商）直營 |
| 入場 | **免費** |
| 營業時間 | 9:30–16:00（體驗最終受付15:30） |
| **休館日** | **每週四**・不定休 |
| 官網 | http://senbei-oukoku.jp/ |

> 7月1日（週三）開館，7月2日（週四）**休館**，不可安排在Day 4。

### 交通

| 方式 | 詳情 |
|------|------|
| 巴士 | 新潟駅→新潟交通巴士→「濁川中学前」下車→步行約5分鐘 |
| 所需時間 | 從新潟駅約30-40分鐘 |

### 體驗內容

| 體驗 | 費用 | 所需時間 | 預約 |
|------|------|----------|------|
| 特大煎餅燒＆調味體驗 | 1,800円/人 | 約30分 | 不需（即場參加） |
| <span style="color:orange">**超特大繪畫煎餅手燒＆調味（平日限定）**</span> | <span style="color:orange">**2,500円/人**</span> | <span style="color:orange">**約30分**</span> | <span style="color:orange">**★ 需事先預約（じゃらん等）**</span> |
| 純調味體驗 | 少量費用 | 短時 | 不需 |

#### 超特大繪畫煎餅說明
- 直徑約25cm的巨型米果
- 自己燒好後，在上面畫圖或寫字
- 獨一無二的紀念品
- 青少年高度適合，不需日文
