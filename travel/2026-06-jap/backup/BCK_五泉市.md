> **此為備選參考資料，現行 Day 2 行程為新潟市散策。**
> 晴天較佳，適合喜歡神社・自然・歷史的替代方案。

---

## 為何考慮此方案

| 原因 | 說明 |
|------|------|
| 交通簡單 | JR直達，新津換乘一次，無需計程車（部分景點除外） |
| 費用低 | 主要景點免費或廉價 |
| 人少清靜 | 非熱門觀光地，自在悠閒 |
| 多樣選擇 | 神社、公園、杉並木、鍾乳洞，可依天氣靈活組合 |

---

## 交通

```
新潟駅 →（JR信越本線 約20分）→ 新津駅 →（JR磐越西線 約15分）→ 五泉駅
```

| 區間 | 時間 | 費用/人 |
|------|------|---------|
| 新潟駅→新津駅 | 約20分 | 約240円 |
| 新津駅→五泉駅 | 約15分 | 約240円 |
| **來回合計** | **約70分** | **約960円/人（四口約3,840円）** |

> ⚠️ 磐越西線は班次少（約1時間に1本），**出發前必須確認時刻表。**

---

## 景點詳解

### 五泉八幡宮 ★★☆

| 項目 | 內容 |
|------|------|
| 性質 | 五泉市の総鎮守，歷史悠久的神社 |
| 費用 | **免費** |
| 開放時間 | 境内24時間 |
| 五泉駅步行 | 約10分 |
| 所需時間 | 約20–30分 |
| 雨天適合 | ★★☆ |
| 特色 | 靜謐境内，夏季緑意盎然，適合起點参拝 |

---

### 村松公園 ★★☆

| 項目 | 內容 |
|------|------|
| 性質 | 村松城跡に造られた公園，日本の歴史公園 |
| 費用 | **免費** |
| 開放時間 | 常時開放 |
| 五泉駅からバス | 約10分（ふれあいバス）＋徒歩 |
| 所需時間 | 約45–60分 |
| 雨天適合 | ★☆☆（屋外） |
| 6月末の見頃 | 緑豊か；春の桜（3,000本）・秋の紅葉が有名（6月は通常期） |

---

### 慈光寺・杉並木 ★★★

| 項目 | 內容 |
|------|------|
| 性質 | 室町時代創建の禅宗寺院，新潟縣天然記念物 |
| 費用 | 外観・杉並木 無料；境内入場 拝観料要確認 |
| 開放時間 | 9:00–17:00（4–10月）／9:00–16:00（11–3月） |
| 五泉駅からタクシー | 約20分（往復タクシー代約3,000–4,000円） |
| 所需時間 | 約45–60分 |
| 雨天適合 | ★★★（霧雨の杉並木は絶景） |
| 特色 | 樹齢数百年の巨杉が参道兩側に並立，雨天・霧中が最も幻想的 |

> **慈光寺は遠隔地のため、タクシー往復が必要。** 事前に五泉タクシーを確認するか、五泉駅周辺で乗車。

---

### 大沢鍾乳洞 ★★★（雨天推薦）

| 項目 | 內容 |
|------|------|
| 性質 | 五泉市指定天然記念物，砂岩質地下洞窟，コウモリ生息 |
| 費用 | 要確認（参考：大人300–500円程度） |
| 開放期間 | **4月〜12月**（冬季閉鎖） |
| 五泉駅からの交通 | タクシー約20–30分（公共交通なし） |
| 所需時間 | 約60分 |
| 雨天適合 | ★★★（地下洞窟，完全不受天氣影響） |
| 注意 | **懐中電灯（手電筒）推薦**；洞内は涼しい（夏でも上着持参） |
| 特色 | 天然鍾乳洞探險，蝙蝠棲息，充滿冒險感，青少年喜愛 |

> **大沢鍾乳洞は公共交通では行きにくい。** タクシーで往復する場合、待機料込みで約5,000–6,000円（全車）見込む。

## 天氣別おすすめ組合せ

### 晴天コース

```
五泉駅
  ↓ 步行10分
五泉八幡宮（参拝 30分）
  ↓ バス10分
村松公園（散步 60分）
  ↓ バス
五泉駅
  ↓ タクシー20分
慈光寺・杉並木（参拝 60分）
  ↓ タクシー
五泉駅→新津→新潟
```

### 雨天コース

```
五泉駅
  ↓ 步行10分
五泉八幡宮（参拝 20分）
  ↓ タクシー
大沢鍾乳洞（探险 60分）
  または
慈光寺・杉並木（霧雨の絶景 60分）
  ↓ タクシー
五泉駅→新津→新潟
```

## 注意事項

- 磐越西線 五泉駅は班次少，務必事先確認時刻表
- 大沢鍾乳洞・慈光寺はタクシー必須，費用が増加
- 五泉市内のバス（ふれあいバス）は本数が非常に少ない，時刻事前確認必要
- 大沢鍾乳洞は夏でも洞内温度が低い（約12–15°C），薄手の上着を持参
