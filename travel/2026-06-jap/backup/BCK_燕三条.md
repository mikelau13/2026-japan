## 主要景點

### 三条鍛冶道場 ★★★

| 項目 | 內容 |
|------|------|
| 地址 | 新潟県三条市元町11-63 |
| 電話 | 0256-34-8080 |
| 營業時間 | 9:00–11:00、13:00–15:30 |
| 休館日 | **週一**（6/30 週二 ✅ 開放） |
| 預約 | **4人以下不需預約** |
| 燕三条駅 | 巴士或計程車約10分 |

#### 體驗課程

| 課程 | 費用（大人） | 費用（中學生以下） | 所需時間 |
|------|------------|-----------------|---------|
| **和釘製作** | 500円 | **250円** | 約40–50分 |
| **ペーパーナイフ製作** | 1,000円 | **500円** | 約40–50分 |
| 包丁研磨 | 300円 | **150円** | 約1小時（需自帶菜刀） |

#### 票價（咱家四口，ペーパーナイフ體驗の場合）

| 家庭成員 | 費用 |
|----------|------|
| 爸媽 ×2 | 1,000円 ×2 = **2,000円** |
| 13歲（中學生） | **500円** |
| 15歲（高校生） | ※1,000円（待確認是否半價） |
| **合計** | **約3,500円** |

#### 體驗內容

- 越後三条鍛冶集団的師傅現場指導
- 將鐵棒放入火爐加熱至高溫，取出後用鐵槌敲打成形
- 視覺衝擊強，親手完成一件金屬工藝品帶回家
- 體驗以**示範→跟做**為主，語言依賴度低

#### ⚠️ 英語支援待確認

- 官網有英文版，顯示有接待外國訪客的意識
- 現場教學語言未明確確認（料為日語）
- 體驗性質以視覺示範為主，語言障礙較低
- **建議出發前致電或請酒店代問**：「外国人向けに英語での説明はありますか？」

## 延伸選項：燕三条＋寺泊 合併

新潟縣觀光局官方推薦行程「燕三条でモノづくり＆寺泊で食旅」：

```
新潟 →（新幹線）→ 燕三条（鍛冶體驗）→（計程車/バス）→ 寺泊（浜焼き）→（JR）→ 新潟
```

> ⚠️ 燕三条→寺泊の交通手段は要確認。行程會比較緊湊，但若想兼顧工藝體驗和海鮮，此路線可行。
