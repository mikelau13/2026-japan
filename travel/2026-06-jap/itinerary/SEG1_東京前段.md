### 入境前必做：Visit Japan Web 登記

[必辦] **請於登機前完成（最遲抵達日本前6小時）**

| 步驟 | 說明 |
|------|------|
| **1. 建立帳戶** | 前往 services.digital.go.jp/en/visit-japan-web/ 以電郵註冊（免費） |
| **2. 登記全家4人** | 可在同一帳戶下新增同行家人，每人各自生成 QR code |
| **3. 填寫資料** | 護照資料（可直接掃描）、航班號、日本聯絡地址（酒店名稱即可）、海關申報 |
| **4. 儲存 QR code** | 建議截圖備份，以防機場無網絡 |
| **5. 機場使用** | 前往自助通關機（KIOSK）→ 掃 QR code → 掃護照 → 指紋 → 拍照 → 完成 |

> 羽田國際線完整支援 Joint Kiosk；入境＋海關一次搞定，無需填紙本表格，節省排隊時間。
