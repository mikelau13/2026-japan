| 設施 | 說明 | 費用 |

## 景點二：清津峡渓谷トンネル ★★★（必去）

日本三大峽谷之一，750米觀景隧道，盡頭為2018年大地藝術祭代表作「水鏡」裝置——淺水反映對面峭壁與天空，是近年日本最熱門打卡地之一。

| 項目 | 內容 |
|------|------|
| 交通 | 越後湯沢駅前巴士約25分（森宮野原行急行） |
| 費用（4月21日起旺季） | 大人（高中生以上）1,200円；中小學生500円 |
| 咱家4人合計 | 爸媽×2（2,400円）＋15歲高中生（1,200円）＋13歲中學生（500円）＝**4,100円** |
| 所需時間 | 隧道往返約30–40分，含交通共約2.5小時 |
| [必辦] **旺季預票** | [必辦] **旺季熱門日需提前網上購票，現場票可能售罄** |

### 隧道內看點

| 位置 | 說明 |
|------|------|
| 第一覧台 | 峽谷第一個觀景窗，垂直石壁近在眼前 |
| 第二覧台 | 圓形鏡面天花板 |
| 第三覧台 | 燈光藝術裝置 |
| **終端水鏡** | 淺水鏡面倒映對面峭壁，視覺衝擊最強；**晴天效果最佳** |

### 終端水鏡——濕腳注意事項

水鏡裝置的地板就是薄薄一層真實的水，走進去拍倒影照片**幾乎無可避免會弄濕鞋底**。

| 位置 | 水深 |
|------|------|
| 中央 | 約小腿高（較深，一般遊客不進入） |
| **邊緣** | **0.5–2cm**（非常淺，大多數人走這裡） |
| 入口附近 | 乾燥拍攝區，可拍到部分倒影，不需踩水 |

**建議準備：**
- 每人備用一雙襪子裝入背包
- 自備小毛巾（現場不提供）
- 最省心做法：穿**可弄濕的涼鞋**或舊鞋進去；或普通鞋沿邊緣小心走
- 山泉水溫度偏低，赤腳時間不宜太長

> 青少年可能覺得踩水很好玩——不是問題，備好換洗襪子即可。

## 建議日程安排

> 清津峡天氣依賴性較高（晴天水鏡效果最佳）。**抵達後先看天色，晴天優先做清津峡。**

### 方案A：先做清津峡（天晴推薦）

| 時間 | 活動 |
|------|------|
| 抵達後 | ぽんしゅ館（駅構內，30–45分） |
| 下午 | 清津峡（巴士25分去程；含遊覽約2.5小時） |
| 傍晚 | 回越後湯沢，**湯沢グランドホテル** check-in |
| 夜間 | 旅館自助晚餐＋大浴場・露天風呂 |
| **翌日早** | 湯沢高原ロープウェイ（8:40開始運行）→ 約10:30完成 |
| **翌日中午前** | 越後湯沢駅→新潟（新幹線約50分） |

### 方案B：先做ロープウェイ（陰天或抵達較晚）

| 時間 | 活動 |
|------|------|
| 抵達後 | ぽんしゅ館→湯沢高原ロープウェイ（步行8分，約2小時） |
| 下午 | **湯沢グランドホテル** check-in |
| 夜間 | 旅館自助晚餐＋大浴場・露天風呂 |
| **翌日早** | 清津峡（巴士25分，約2.5小時） |
| **翌日中午前** | 越後湯沢駅→新潟（新幹線約50分） |
